# PantryPulse 🛒

A Flask-based Grocery and Pantry Management System designed to help users manage pantry items, track expiry dates, purchase groceries, and reduce food waste.

## 🚀 Features

* User Registration and Login
* Grocery Product Management
* Pantry Management
* Purchase Management
* Expiry Alerts
* Recipe Suggestions
* Feedback Management
* Analytics Dashboard
* User Profile Management

## 🛠️ Technologies Used

* Python
* Flask
* MySQL
* HTML
* CSS
* JavaScript
* Jinja2

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/tharunrajit123/pantrypluse.git
```

### 2. Open the project

```bash
cd pantrypluse
```

### 3. Install required packages

```bash
pip install flask mysql-connector-python
```

### 4. Configure MySQL

Create the required MySQL database and tables for the application.

Update the database configuration in the application with your local MySQL credentials.

### 5. Run the application

```bash
python app.py
```

Then open the local Flask URL shown in the terminal.

## 🎯 Project Objective

PantryPulse aims to make grocery and pantry management easier by helping users keep track of their food items, purchases, and expiry dates while reducing unnecessary food waste.
